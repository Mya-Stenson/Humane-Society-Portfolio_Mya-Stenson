# Mya Stenson — Humane Society Creative Portfolio

A responsive, playful portfolio site built with plain HTML, CSS, and JavaScript. It uses a warm paper-and-sage palette, custom CSS/SVG illustrations, and gentle hand-drawn details.

## Files
- `index.html` — page content and project links
- `style.css` — layout, responsive styles, illustrations, and motion
- `script.js` — mobile menu, current year, dog-photo fallback, and scroll reveals
- `assets/sustainable-eats-reflection.pdf` — writing sample
- `assets/graphic-design-sample.pdf` — supplementary PDF sample
- `images/my-dogs.jpg` — add your own photo here

## Before publishing
1. Add a photo of your dogs at `images/my-dogs.jpg`. JPG is recommended. If you use another format or filename, update the `src` in `index.html`.
2. In `index.html`, replace `REPLACE-WITH-YOUR-EMAIL` in the `mailto:` link with your email address.
3. Open `index.html` locally to check the layout, project links, and photo.
4. Upload the contents of this folder to the root of your GitHub repository. Keep the folder structure intact.
5. In GitHub, open **Settings → Pages** and choose the branch/folder used for deployment.

## Notes
- The project descriptions are intentionally modest and describe the work as learning projects or concepts rather than client commissions.
- The Sustainable Eats iterations are grouped as one evolving project rather than presented as unrelated projects.
- The dog-photo box is a friendly local fallback, not a finished portfolio image. Add your actual photo before sharing the site with employers.
- Check that the PDFs and all project links work after publishing.
